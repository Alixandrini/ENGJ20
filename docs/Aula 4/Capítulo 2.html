Introdução

Agora que podemos ler nossos dados para o computador (Capítulo 1), vamos calcular alguns índices de vegetação.

O Índice de Vegetação por Diferença Normalizada (NDVI) é tão onipresente que até tem uma entrada na Wikipedia. Se você está aqui para aprender a fazer processamento de imagens de Sensoriamento Remoto usando GDAL e Python, provavelmente não precisa de introdução a este índice. Se precisar de uma revisão, consulte o link da Wikipedia para o NDVI.

Este capítulo será muito direto. Já vimos como ler nossas imagens em um array NumPy — este capítulo simplesmente estenderá essas ferramentas, mostrando como fazer cálculos simples em objetos NumPy.

Vamos trazer o código anterior para abrir nossa imagem e ler os dados para um array 3D:

from osgeo import gdal_array

# Importa o módulo NumPy
import numpy as np

# A importação do 'from __future__ import print_function' (Python 2)

dataset = gdal.Open('https://github.com/Alixandrini/ENGJ20/raw/refs/heads/main/Aula%204/LE70220491999322EDC01_stack.gtif', gdal.GA_ReadOnly)

    # Tente abrir o dataset (substitua o caminho)
    dataset = gdal.Open('caminho_para_sua_imagem.tif', gdal.GA_ReadOnly)
except:
    print("ERRO: Dataset não encontrado. Certifique-se de carregar e referenciar seu arquivo raster no Colab.")

if dataset is not None:
    # Aloca nosso array usando o tipo de dado da primeira banda
    image_datatype = dataset.GetRasterBand(1).DataType

    image = np.zeros((dataset.RasterYSize, dataset.RasterXSize, dataset.RasterCount),
                     dtype=gdal_array.GDALTypeCodeToNumericTypeCode(image_datatype))

    # Percorre todas as bandas no dataset
    for b in range(dataset.RasterCount):
        # Lembre-se: o índice do GDAL é 1-based, o Python é 0-based -- então adicionamos 1
        band = dataset.GetRasterBand(b + 1)

        # Lê os dados da banda na terceira dimensão do nosso array
        image[:, :, b] = band.ReadAsArray()


    # Assumindo a ordem de bandas do tutorial (Red na banda 3, NIR na banda 4, índice 2 e 3)
    print('Média da banda Vermelha (Red): {r}'.format(r=image[:, :, 2].mean()))
    print('Média da banda do Infravermelho Próximo (NIR): {nir}'.format(nir=image[:, :, 3].mean()))

Mesmo a partir de estatísticas de média simples em toda a imagem, podemos observar o contraste entre a banda vermelha (Red) e a banda do Infravermelho Próximo (NIR).

Cálculo do NDVI

Para calcular o NDVI, podemos simplesmente usar operadores aritméticos padrão do Python, pois essas operações no NumPy são vetorizadas. Assim como no MATLAB, R e outras linguagens de alto nível, NUNCA itere (faça um loop) sobre um array NumPy se puder evitar.

O cálculo do NDVI é:

\[ NDVI = \frac{(NIR - Red)}{(NIR + Red)} \]

if dataset is not None:
    # Índices das bandas (assumindo a indexação Python 0-based: 3ª banda é índice 2, 4ª é índice 3)
    b_red = 2
    b_nir = 3

    # Cálculo do NDVI (a divisão com '/' funciona corretamente no Python 3)
    ndvi = (image[:, :, b_nir] - image[:, :, b_red]) / (image[:, :, b_red] + image[:, :, b_nir])

    print(f"Primeiros valores da matriz NDVI (float64):\n{ndvi}")
    print(f"\nValor máximo do NDVI: {ndvi.max()}")

Nota sobre o Tipo de Dados (Float)

O código acima funciona perfeitamente no Python 3.

No Python 2, a divisão de um inteiro por outro inteiro sempre produz um resultado inteiro (ex: \(3/4 = 0\)). Isso faria com que todos os valores de NDVI fossem 0 se a imagem de entrada fosse do tipo inteiro (int16). O Python 3 alterou esse comportamento, fazendo com que / resulte em um ponto flutuante.

No entanto, é uma boa prática ser explícito com os tipos de dados envolvidos nos cálculos, para maior clareza e para garantir que a divisão ocorra em ponto flutuante, independentemente do tipo de dado das bandas raster. Para isso, convertemos o denominador (ou numerador) para um ponto flutuante (ex: np.float64):

if dataset is not None:
    # Conversão explícita do denominador para np.float64 para garantir resultados em ponto flutuante
    ndvi = (image[:, :, b_nir] - image[:, :, b_red]) / \
            (image[:, :, b_nir] + image[:, :, b_red]).astype(np.float64)

    print('Matriz NDVI: ')
    print(ndvi)

    print('\nMáximo NDVI: {m}'.format(m=ndvi.max()))
    print('Média NDVI: {m}'.format(m=ndvi.mean()))
    # Usando o NumPy para o cálculo da mediana
    print('Mediana NDVI: {m}'.format(m=np.median(ndvi)))
    print('Mínimo NDVI: {m}'.format(m=ndvi.min()))

    # Não se esqueça de fechar o dataset e liberar a memória
    dataset = None

O cálculo parece correto, com valores de NDVI variando entre aproximadamente 0 e 1.
